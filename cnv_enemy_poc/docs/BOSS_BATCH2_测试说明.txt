Boss 第二批真机测试 — 关卡前哨 m60_42_37_00

============================================



【怎么装】

1. 确认 me3 已注册 cnv-enemy-poc 包（见 cnv_enemy_me3_snippet.toml）

2. 双击运行：tools\cnv_enemy_poc\BOSS_BATCH2.bat

   （会先 restore 清旧叠加，再 boss-batch2）

3. 完全退出游戏 → Start_Convergence.bat → 新档或 NG → 去关卡前哨

【卢恩怎么测】

进图前记下当前卢恩总数。按 A→B→C 顺序击杀三个卢恩对照槽，每次记录：

  - 击杀后卢恩增加了多少

  - 是否与「替换后怪物」档次相符（大树守卫 >> 野狗 >> 矛兵）

本批 POC 未改 ItemLotParam，预期掉落跟 **新 npc** 走，不是原士兵槽。



【改动原则（尽量少动）】

- 只换：模型 + NpcParam + ThinkParam + CharaInit

- 坐姿兵清 BackupEventAnimID

- 不改：坐标、巡逻路线、EntityGroup、事件脚本



【真机请记录】

□ 龙：能否看到 / 能否开战 / 卡地形吗

□ 艾尔登之兽：外观对不对 / 招式 / 崩溃

□ 卢恩 A/B/C 各掉多少（截图或数字）

□ 有无 T-pose / 乱触发事件
