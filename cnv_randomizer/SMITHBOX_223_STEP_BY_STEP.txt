================================================================================
  Smithbox 2.2.3 用法 — 法魂 3.0 随机合并（中文逐步点击）
================================================================================

【先说清楚】
  Smithbox 2.x 没有「File → Open regulation.bin」这种直接打开 bin 的选项。
  必须先「建项目(Create Project)」，把项目目录指到放 regulation.bin 的文件夹。
  对你来说就是：Game\mod\  （ME3 读的就是这里的 bin）

  Smithbox 界面是英文，下面每条都写了英文菜单名 + 中文意思。

================================================================================
  第 0 步：确认 bin 是好的（合并前必做）
================================================================================

  用资源管理器看这两个文件大小（右键 → 属性）：

    V:\games\Elden Ring\Game\mod\regulation.bin
    V:\games\Elden Ring\Game\regulation.bin

  正确大小约：2,364,448 字节（约 2.25 MB）

  若是 3,136,624（约 3.0 MB）→ 已被升级成原版，法魂会坏。
  先双击运行：tools\cnv_randomizer\RESTORE_CNV_REGULATION.bat

================================================================================
  第 1 步：启动 Smithbox
================================================================================

  方式 A（推荐）：双击
    tools\cnv_randomizer\OPEN_SMITHBOX_CNV.bat

  方式 B：直接双击
    V:\games\Smithbox-2-2-3-2026-06-26-a\Smithbox.exe

  若一闪就关：显卡可能不支持 Vulkan，见文末「闪退」。

================================================================================
  第 2 步：新建项目（这就是「打开 bin」的正确方式）
================================================================================

  打开后首页可能是：
    - Project Selection（项目选择）
    - 或 No Project（没有项目）

  点其中一个按钮（名字可能略有不同）：
    Create Project    = 创建项目
    New Project       = 新建项目

  弹出窗口「Project Creation」里填：

  ┌─────────────────────────────────────────────────────────────┐
  │ Project Name（项目名）                                       │
  │   填：cnv_random   （随便起名，方便辨认即可）                  │
  ├─────────────────────────────────────────────────────────────┤
  │ Project Type（项目类型）★ 最重要 ★                           │
  │   选：Elden Ring                                             │
  │   不要选：Elden Ring: Nightreign  （那是夜王 DLC 专用）        │
  ├─────────────────────────────────────────────────────────────┤
  │ Project Directory（项目目录）★ 你的 mod bin 在这 ★            │
  │   点文件夹按钮，选这个文件夹：                                 │
  │   V:\games\Elden Ring\Game\mod                               │
  │   （里面必须有 regulation.bin）                               │
  ├─────────────────────────────────────────────────────────────┤
  │ Data Directory（游戏数据目录）                                 │
  │   填：V:\games\Elden Ring\Game                               │
  │   （这一层有 eldenring.exe）                                  │
  │   有时选完 Project Type 会自动填，不对就手动改                  │
  ├─────────────────────────────────────────────────────────────┤
  │ Editors / Tools（编辑器，若有勾选）                            │
  │   只勾：Param Editor（参数编辑器）                             │
  │   别的（Map / Model / Text…）全不勾 → 加载快很多               │
  └─────────────────────────────────────────────────────────────┘

  最后点：Create（创建）

  第一次加载可能要 1～3 分钟，等底部日志跑完。

================================================================================
  第 3 步：绝对不要升级 regulation
================================================================================

  若弹出：
    Upgrade Regulation / Param Upgrader / 升级 regulation
  → 点 No / Cancel / 取消 / 否

  点了「升级」bin 会变成 3,136,624，27 职业和圣所都会坏。

  也不要用旧工程：
    V:\games\box\   （ER1161 那个）

================================================================================
  第 4 步：打开参数编辑器
================================================================================

  加载完成后，窗口上方或左侧有编辑器标签，点：

    Param Editor    = 参数编辑器

  左侧是 Param List（参数表列表），顶部有搜索框，输入：

    ItemLotParam_map

  在列表里单击选中 ItemLotParam_map（地图掉落表，我们要改的就是它）。

================================================================================
  第 5 步：Mass Edit（批量改 1244 个掉落，比 Import CSV 安全）
================================================================================

  打开 Mass Edit 窗口，位置（2.2.3 实测）：

    顶部菜单 View → Mass Edit    ← 点这个！不是 Tools 菜单

  Tools 菜单里只有 Sort Rows / Data Comparison 等，没有 Mass Edit，那是正常的。

  点 View → Mass Edit 后，下方或右侧会出现 Mass Edit 面板。
  若仍没有，再试：右侧竖条 Tools 面板里找 Mass Edit 按钮。

  窗口标题一般是：Mass Edit

  1) 用记事本打开（不要改内容，只复制）：
       V:\games\Elden Ring\Game\tools\cnv_randomizer\output\ItemLotParam_map.massedit

  2) Ctrl+A 全选，Ctrl+C 复制

  3) 粘贴到 Mass Edit 窗口上方的大文本框（Input / Commands）

  4) 点 Apply（应用）

  5) 等几秒，日志里应显示成功（可 Ctrl+Z 撤销，放心试）

  不要用 Data → Import CSV（整张表导入，更容易搞坏法魂表）。

================================================================================
  第 6 步：保存
================================================================================

  按键盘：Ctrl + S

  或菜单：
    File → Save Project
    File → Save All Modified Params   （若有这一项）

  保存目标应是项目目录里的 bin，即：
    V:\games\Elden Ring\Game\mod\regulation.bin

================================================================================
  第 7 步：保存后自检（30 秒）
================================================================================

  右键 mod\regulation.bin → 属性 → 大小

  ┌──────────────────┬────────────────────────────┐
  │ 约 2,364,448     │ 正常，可以进游戏测          │
  │ 3,136,624        │ 错了！恢复 bin，重来，别升级 │
  └──────────────────┴────────────────────────────┘

  大小可以和合并前差几 KB，但不能变成 3.1MB。

================================================================================
  第 8 步：进游戏测试
================================================================================

  1) Start_Convergence_ME3.bat 启动
  2) 必须新开 CNV 存档（旧档可能已坏）
  3) 检查：27 职业、圣所金色道具、能出门

================================================================================
  英文菜单速查
================================================================================

  Create Project     创建项目
  Project Type       项目类型 → 选 Elden Ring
  Project Directory  项目目录 → Game\mod
  Data Directory     游戏目录 → Game
  Param Editor       参数编辑器
  Mass Edit          批量编辑
  Apply              应用
  Upgrade            升级（不要点）
  Save Project       保存项目

================================================================================
  常见问题
================================================================================

  Q: 找不到「打开 bin」？
  A: 2.2 没有。用第 2 步 Create Project，Project Directory 指到 mod 文件夹。

  Q: 加载后 Param 列表是空的 / Failed to find regulation.bin？
  A: 检查 Project Type 是不是 Elden Ring（不是 Nightreign）；
     Project Directory 是不是 Game\mod（里面有 regulation.bin）；
     Data Directory 是不是 Game（有 eldenring.exe）。

  Q: Smithbox 一闪就关？
  A: 编辑文件（用记事本）：
     %LocalAppData%\Smithbox\Configuration\Configuration.json
     把 System_RenderingBackend 改成 0（改用 OpenGL），保存后再开。

  Q: 合并后职业变 10 个？
  A: bin 被升级成原版了。RESTORE_CNV_REGULATION.bat 恢复，按本文重来，拒绝 Upgrade。
