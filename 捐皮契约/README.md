# 捐皮契约

**黑白名单人工审计真源**（与 `reports/` 分离）。

| 文件 | 用途 |
|------|------|
| `捐皮白名单_当前.md` / `.json` | 可捐皮一览（按 1～6 池） |
| `捐皮黑名单_当前.md` / `.json` | 禁捐且白名单无同名 |
| [T063_新扫捐皮候选表.md](./T063_新扫捐皮候选表.md) | **T-063** 新入库图捐皮候选；名称相近者见表内附录 |
| [捐皮池三层缓存契约.md](./捐皮池三层缓存契约.md) | **① 捐皮全量库 + 契约 → ③ prep** 合成规则（2026-08-06） |

## 流程

1. **审计**：你报序号/规则 → AI **只改本目录**里的表  
2. **实装**：`python cnv_randomizer/_apply_donor_contract.py` → allowlist / manual_includes / 龙类 never_donor → **`prep`（仅重合成 ③，不重复扫捐皮）** → `smoke --map-filter`
3. **不必再导出覆盖本表**（除非你要用脚本核对实装结果）

**捐皮缓存（目标口径）**：全图捐皮扫一次入 **①**；白名单变动只重 **③**。详见 `捐皮池三层缓存契约.md`。

`reports/` 仍放槽位底表、m61 扫描、体型表等**机器生成**统计；勿与捐皮审计混放。
