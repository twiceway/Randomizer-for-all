## 一句话

分类开关分册（已无槽清理 + 永不进池踢出）→ **离线 JSON**（可捐种类 + 所属分开开关）→ 主程序洗牌目标池 = 表内 ∩ GUI 开关为开。

## 口径

| 项 | 口径 |
|----|------|
| **物品池真源** | `reports/分类开关/` 分册现有行（一种一行） |
| **分开开关** | 每条带 `switch_key`；关着的类不进 `shuffle_target_pool` |
| **世界槽数** | 分册列 + JSON `world_slot_count`（备查；洗牌仍按现网源槽 multiset） |
| **槽发现** | 现网 MSB 拾取索引 + 地图 Boss/固定奖；**不**读旧「物品槽审计允许表」 |
| **护符** | 分册 0 条；表中不出现；洗牌硬排除保持 |
| **缺表** | 硬失败，禁止静默退回全库池 |
| **同 id 跨开关** | 允许（武器/护甲等表撞号）；行键 `(item_id, switch_key)`；建池按开着的开关取 id 并集 |
| **同开关同 id 两名冲突** | 同步脚本报错退出 |

## 分册 → switch_key

| 分册 | switch_key | GUI |
|------|------------|-----|
| 装备_武器_* | weapon | randomize_categories.weapon |
| 装备_护甲_* | armor | randomize_categories.armor |
| 装备_法术_* | magic | randomize_categories.magic |
| 道具_任务_* | quest | randomize_goods_groups.quest |
| 道具_重要道具_* | important | randomize_goods_groups.important |
| 道具_强化材料_* | upgrade | randomize_goods_groups.upgrade |
| 道具_杂项_* | craft | randomize_goods_groups.craft |
| 装备_护符_* | （跳过） | 永不进池 |

`switch_kind`：`weapon`/`armor`/`magic` → `equip_cat`；其余 → `goods_group`。
