## 口径

| 项 | 口径 |
|----|------|
| **进池** | **槽参与**洗牌 **且** **物品进池**（可作捐） |
| **分类开关** | GUI 关着的大类/子类 → 运行时不洗、不捐 |
| **血瓶 / 蓝瓶 / 灵药瓶** | 永不进池 |
| **增量** | 新审完的分册加入同步脚本 `BOOKLETS` 后重跑 → 按 `channel+seq` 覆盖合并 |
