# 离线参数大表

给 AI / 审计用的**全量敌人参数快照**（人读本页即可）。

## 这是啥

- **文件**：同目录 `离线参数大表.json`（约 6.5MB）
- **覆盖**：法魂 Convergence 现网 `NpcParam.csv` **全部 7818** 行（不是旧版「只扫地图模板」那 2545 个）
- **联表**：同 ID 能对上的 `NpcThinkParam`（视距/嗅觉等）；对不上则 `think` 为空
- **有效血**：与白名单同一套估法（表血 × 加血特效；必要时代理/同族回填）
- **不是**：未改装原版艾尔登法环实测血量

## 怎么重扫

```bat
cd /d V:\1_mel\Ringrandom\cnv_randomizer
python _build_offline_param_table.py
```

会覆盖本目录的 `离线参数大表.json` / `.md` 元信息。
